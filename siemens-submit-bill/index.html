SIEMENS Submit Bill — เครื่องมืออ่าน PDF invoice อัตโนมัติ

อัปโหลด PDF invoice หลายไฟล์ + ไฟล์ Invoice_Email_Sender.xlsx เดิม ระบบจะอ่านและกรอกให้ ส่วนที่อ่านอัตโนมัติไม่ได้จะถูก flag ให้กรอกเอง
ข้อจำกัดที่ต้องรู้ก่อนใช้งาน: วันที่เซ็นดิจิทัล (Digital_Sign_Date) เป็น "ภาพประทับตรา" ในเอกสาร ไม่ใช่ตัวอักษร ระบบอ่านช่องนี้อัตโนมัติไม่ได้ (ทดลองใช้ OCR แล้วไม่น่าเชื่อถือพอในทางปฏิบัติ) — ช่อง Digital_Sign_Date จะว่างไว้เสมอ ต้องเปิดไฟล์ดูแล้วกรอกเอง ส่วนเลข PO บางไฟล์อาจเป็นภาพสแกน (อ่านไม่ได้) ระบบจะ flag แถวเหล่านี้เป็นสีส้มให้ตรวจสอบก่อนสร้างไฟล์ Excel ทุกครั้ง — ห้ามข้ามการตรวจสอบแถวที่ถูก flag
ไฟล์นี้เป็น standalone HTML (ไม่ผ่าน Cowork) ต้องเปิดด้วยเบราว์เซอร์ปกติ (Chrome/Edge) และต้องมีอินเทอร์เน็ตตอนเปิดครั้งแรก (โหลด library อ่าน PDF/Excel จาก CDN) ข้อมูลทั้งหมดประมวลผลในเครื่องคุณเอง ไม่มีการส่งไฟล์ออกไปที่ไหน

แถวสีส้ม = ต้องตรวจสอบ/กรอกเอง (PO ไม่ตรง, อ่านไม่ได้, หรือเป็น DEBIT MEMO) — กดปุ่ม "เปิดไฟล์" เพื่อดู PDF จริงแล้วพิมพ์ค่าที่ถูกต้องในช่องได้เลย ติ๊กออกถ้าไม่ต้องการรวมแถวนั้นลงไฟล์ Excel

ระบบจะไม่แก้ไขไฟล์ต้นฉบับโดยตรง — ปุ่ม "สร้างไฟล์ Excel" จะสร้างไฟล์ใหม่ชื่อ Invoice_Email_Sender_updated.xlsx ให้ดาวน์โหลด แล้วคุณนำไปแทนที่ไฟล์เดิมเอง
ข้อควรระวัง: library ที่ใช้เขียนไฟล์ Excel (SheetJS รุ่นฟรี) อาจไม่รักษา dropdown, conditional formatting, หรือสีของเซลล์เดิมไว้ครบ 100% เมื่อสร้างไฟล์ใหม่ทั้งไฟล์ ถ้าไฟล์ต้นฉบับของคุณมี dropdown หรือฟอร์แมตพิเศษ แนะนำให้ใช้ปุ่ม "คัดลอกเฉพาะแถวใหม่ (TSV)" แล้วไปวางในไฟล์จริงที่เปิดอยู่ใน Excel เอง แทน จะปลอดภัยต่อไฟล์ต้นฉบับกว่า
